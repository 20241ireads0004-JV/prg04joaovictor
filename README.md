<h1>🏆 TODO ESPORTE</h1>
<hr>
O TODO ESPORTE é uma aplicação web que vai implementar sistemas de classificação, sorteio (aleatório ou baseado na avaliação e classificação), estatísticas (gols, pontos, vitórias...) e avaliações dos atletas/usuários, também permitirá que grupos de diferentes esportes divulguem o horário que ocorre a prática do esporte e o local e promovam campeonatos internos, atraindo novos praticantes e tornando o grupo mais competitivo e organizado.
<hr>
<h2>ESTRUTURA DO PROJETO</h2>
<hr>
<p>infraestucture: ficam os arquivos principais e recursos usados em todo o projeto.</p>
<p>/assets:</p>
<p>css: fica os arquivos de estilização.</p>
<p>fonts: fontes utilizadas no projeto.</p>
<p>images: imagens utilizadas no projeto.</p>
<p>js: scripts JavaScript.</p>
<p>/pages:</p>
<p>about: página "sobre".</p>
<p>contacts: página para contato.</p>
<p>index.html: página inicial.</p>
